ASCII Painter ships unmodified builds of FFmpeg 9.0.2 (ffmpeg and ffprobe) as separate
programs. ASCII Painter runs them as child processes and does not link to them.
The Linux builds retain dependencies on system C/C++ runtime libraries.

These builds include GPL components (libx264) and are therefore distributed under the
GNU General Public License, version 3 or later:
https://www.gnu.org/licenses/gpl-3.0.html

FFmpeg source code for the shipped version:
https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz

Build sources and their build scripts:
- Windows: https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2 (https://www.gyan.dev/ffmpeg/builds/)
- Linux: https://ffmpeg.martin-riedl.de/ (build scripts are linked from that page)

Exact archives and checksums: tools/release_package.py in the ASCII Painter source.
